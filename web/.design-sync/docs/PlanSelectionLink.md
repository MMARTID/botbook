Enlace de elección de plan que vive dentro de una tarjeta de precio. `featured`
lo convierte en el CTA sólido del plan recomendado; sin él es el tratamiento
secundario. `preselected` es para cuando se llega desde la landing con el plan
ya decidido.

`planId` es `"inicio" | "pro" | "scale"` y `planName` el rótulo visible.
