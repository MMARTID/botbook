Lista de los cuatro pasos que el negocio tiene que completar para que el agente
pueda reservar: horario, servicios, equipo y calendario. Cada paso enlaza a su
sección de `/ajustes`, y la barra superior muestra el progreso.

No recibe props: lee `["onboarding-state"]` de React Query. Se descarta con la
X y desaparece al completarse.
